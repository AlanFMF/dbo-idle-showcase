# Avisos e propriedade intelectual

Este repositório apresenta uma seleção de código e documentação do projeto DBO IDLE para avaliação profissional e educacional.

## Código

O conteúdo é disponibilizado para visualização como portfólio. Nenhuma licença open source é concedida automaticamente. A ausência de uma licença significa que reprodução, redistribuição e uso comercial dependem de autorização do autor.

## Recursos de terceiros

Sprites, mapas, sons, clientes, arquivos `.dat`/`.spr`, catálogos extraídos e outros recursos provenientes de jogos ou projetos de terceiros não fazem parte deste repositório.

Nomes, marcas e personagens eventualmente citados no contexto histórico do projeto pertencem aos respectivos titulares. O DBO IDLE é um projeto independente e não possui vínculo, patrocínio ou aprovação oficial dessas empresas.

## Dados

Nenhuma conta, personagem, pagamento, e-mail, endereço IP, sessão ou outro dado de jogador está incluído na versão pública.
