# DBO IDLE

Vitrine técnica de um jogo online para navegador desenvolvido com JavaScript, Node.js, PostgreSQL e WebSocket.

O projeto inclui sistemas de progressão, personagens, transformações, hunts, bosses, guildas, party, mercado, missões, pagamentos e administração em infraestrutura Linux.

> Repositório em preparação e revisão de segurança.

Projeto independente desenvolvido para fins de portfólio, sem vínculo oficial com as franquias que serviram como inspiração.
